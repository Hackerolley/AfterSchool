# AfterSchool

Backend implementation for the multi-tenant online school management system in the supplied architecture blueprint. The current release covers the blueprint's Phase 1–4 milestone: foundation, authentication, user management, and academic structure.

- **Backend:** [server/README.md](./server/README.md) — API setup, environment configuration, tenant provisioning, and the endpoint reference.
